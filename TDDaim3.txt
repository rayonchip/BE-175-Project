TDD Cycle Summary — Aim 3 PLSR Analysis
========================================

Overview
--------
Extended the CKD project with Partial Least Squares Regression (PLSR) analysis
in aim3_plsr.py. The implementation was built in two stages (Parts 1-2 and Part 3)
following strict TDD: tests written first, then source code. All 28 tests were
red before any implementation existed and green immediately after.


Functions Implemented
---------------------
  Part 1-2:
    - fit_plsr(X, y, n_components)
        Fits a PLSRegression model and returns it.
    - select_n_components(X, y, max_components=10)
        Chooses the optimal component count via 5-fold cross-validated R2.
    - compute_vip(model, feature_names)
        Computes VIP (Variable Importance of Projection) scores, returns a
        DataFrame sorted descending by vip.

  Part 3:
    - bootstrap_vip(X, y, n_components, feature_names, n_bootstrap=200, random_state=42)
        Resamples with replacement n_bootstrap times, refits PLSR each time,
        recomputes VIP scores, and reports each feature's stability (fraction of
        bootstrap iterations where VIP > 1) and mean VIP.
    - condition_number(X)
        Returns the condition number of the feature matrix as a float — a
        direct measure of multicollinearity (high value = correlated features,
        ill-conditioned system).
    - bootstrap_coef_ci(X, y, n_components, feature_names, n_bootstrap=200, ci=95, random_state=42)
        Bootstrap-samples the data, refits PLSR each time, and computes
        percentile-based confidence intervals on each feature's regression
        coefficient. Returns mean_coef, ci_lower, ci_upper, ci_width.

Test Classes and Rationale
--------------------------
TestFitPlsr (4 tests)
  Checks return type (PLSRegression), fitted state (x_scores_ present),
  that the requested component count is respected, and that score rows equal
  the training sample count.

TestSelectNComponents (3 tests)
  Checks return type (int), that the result is within [1, max_components],
  and that max_components is never exceeded for three different bounds.

TestComputeVip (6 tests)
  Checks DataFrame return, exact column set, row count equals feature count,
  all scores non-negative, sorted descending, and that at least one CKD
  biomarker exceeds VIP > 1.

TestBootstrapVip (6 tests)
  Checks DataFrame return, exact column set {feature, stability, mean_vip},
  row count, stability values in [0, 1], mean_vip non-negative, and that
  at least one of hemo or sg appears in the top 5 by stability — verifying
  that the dominant CKD biomarkers are reliably identified across resamples.

TestConditionNumber (3 tests)
  Checks float return, value >= 1 (lower bound by definition), and value > 10
  on the real CKD dataset — confirming clinical features are multicollinear,
  which motivates PLSR over ordinary regression.

TestBootstrapCoefCi (6 tests)
  Checks DataFrame return, exact column set {feature, mean_coef, ci_lower,
  ci_upper, ci_width}, row count, all features present, ci_lower <= ci_upper,
  and ci_width >= 0.

Key Design Decisions
--------------------
- np.asarray conversion: both bootstrap functions convert inputs at entry so
  that pandas Series/DataFrame with non-contiguous indices work correctly with
  position-based bootstrap sampling.
- Percentile bootstrap CI: simpler and more robust than BCa for this dataset
  size; gives correct intervals without requiring jackknife estimates.
- condition_number uses the full scaled feature matrix (not training split)
  because multicollinearity is a property of the feature space, not the split.
- VIP formula uses normalized weights (W_norm): column-normalizing the weight
  matrix ensures each component contributes proportionally to its explained
  variance in Y, not its raw magnitude.
- bootstrap_vip reindexes the per-iteration VIP Series by feature name before
  building the DataFrame, so sort order variation between iterations does not
  corrupt the column alignment.
