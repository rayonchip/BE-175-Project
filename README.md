# BE-175-Project

## Setup

**Requirements:** Python 3, with the following packages:
```bash
pip install pandas scikit-learn matplotlib pytest
```

**Clone the repo:**
```bash
git clone <repo-url>
cd BE-175-Project
```

> Always run scripts from the project root (`BE-175-Project/`). All scripts
> use a relative path to `Training Data/ckd_cleaned.csv` and will fail with
> a `FileNotFoundError` if run from a subfolder.

---

## Running the code

Run each aim in order, or jump straight to the summary.

**Aim 1** — classification (logistic regression + decision tree):
```bash
python aim1_classification.py
```
Prints accuracy, precision, recall, specificity, and F1 for both models.
Saves: `confusion_matrices.png`

---

**Aim 2** — cross-validation, hyperparameter tuning, feature importance, sensitivity analysis:
```bash
python aim2_analysis.py
```
Prints CV results, best hyperparameters, feature importances, and sensitivity deltas.
Saves: `lr_feature_importance.png`, `dt_feature_importance.png`, `lr_sensitivity.png`, `dt_sensitivity.png`, `regularization_path.png`

---

**Aim 3** — PLSR, VIP scores, bootstrap stability, sensitivity, ridge comparison:
```bash
python aim3_plsr.py
```
Prints optimal components, VIP scores, condition number, bootstrap stability, coefficient CIs, perturbation sensitivity, and PLSR vs Ridge CI widths.
Saves: `vip_scores.png`, `bootstrap_stability.png`, `plsr_sensitivity.png`

---

**Summary** — cross-aim synthesis answering all three research questions:
```bash
python summary.py
```
Prints a consensus feature ranking and a three-question narrative tying all aims together.
Saves: `summary_figure.png` (2×2 panel: consensus ranking, VIP scores, bootstrap stability, PLSR sensitivity)

> `summary.py` takes ~30 seconds — it reruns the bootstrap (200 iterations) internally.

```bash
python -m pytest test_aim1.py -v   # 35 tests
python -m pytest test_aim2.py -v   # 45 tests
python -m pytest test_aim3.py -v   # 34 tests
python -m pytest -v                # all 114 at once
```

All 114 tests must pass before merging any new code.
